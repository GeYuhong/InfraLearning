# FSDP/HSDP 分片训练

本目录研究全分片数据并行（FSDP）和混合分片数据并行（HSDP）。结合 `dots-score` 的实现和提交历史，梳理参数、梯度和优化器状态如何分布在不同 rank 上，以及这些状态在训练过程中如何收集、计算、归约和释放。

## 重点内容

- **分片模型**：FSDP 与 HSDP 的分组方式、分片维度和复制关系，以及它们对通信量和显存占用的影响。
- **实现与表示**：Megatron FSDP、Custom FSDP、DTensor 等相关实现的职责、张量布局和接口约定。
- **状态生命周期**：参数 all-gather、梯度 reduce-scatter、重新分片、预取和缓冲区复用的触发时机与依赖。
- **分片粒度与模块适配**：模块边界、encoder 独立分片、不均匀分片，以及与其他并行方式组合时的约束。
- **正确性与持久化接口**：梯度和参数更新的一致性、内存生命周期问题，以及分片状态对 checkpoint 保存和恢复的要求。
