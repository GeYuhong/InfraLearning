# VLM/Omni 多模态模型与训练集成

本目录研究视觉语言模型（VLM）和 Omni 多模态模型的整体组装与训练接入。结合 `dots-score` 的实现和提交历史，梳理 LLM、视觉编码器、音频编码器和 adaptor 如何协作，以及不同模态如何进入统一的训练步骤。

## 重点内容

- **模型组装**：LLM、VE、AE、adaptor 的输入输出和连接关系，以及各模块的参数与梯度路径。
- **模型接入**：LLaVA、Qwen-VL、NVLM、MiMo 等相关模型的 provider、接口和集成差异。
- **多模态数据流**：文本、图像、音频等输入如何转成模型表示，如何拼接并与训练目标对应。
- **训练阶段与参数管理**：冻结参数、LLM 到 Omni 的切换，以及不同模块参与训练时的状态和初始化要求。
- **组合适配**：流水线、编码器分片、负载均衡和图执行接入整体模型时的依赖与正确性检查。
