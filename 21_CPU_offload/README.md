# 激活、优化器状态的 CPU Offload 与显存优化

本目录研究激活、优化器状态及相关缓冲区在 CPU 与 GPU 之间的卸载和回载，以及训练中的显存生命周期管理。结合 `dots-score` 的实现和提交历史，梳理哪些数据可以暂时离开 GPU、何时需要恢复，以及搬移如何与计算配合。

## 重点内容

- **卸载对象与时机**：激活、优化器状态，以及 encoder 输入、输出和梯度的生命周期与使用边界。
- **数据搬移**：GPU 到 CPU（D2H）、CPU 到 GPU（H2D）的异步传输，pinned memory 和缓冲区复用。
- **调度配合**：PP-aware offload、预取和计算通信重叠，分析回载完成与张量使用之间的依赖。
- **内存管理**：引用释放、buffer/pool 管理、显存峰值、内存泄漏和 CPU 内存压力的定位。
- **效果验证**：数据与梯度一致性、额外传输开销，以及显存节省和训练吞吐之间的取舍。
