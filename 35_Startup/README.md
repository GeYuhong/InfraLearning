# 启动、Warmup 与编译/Autotune 缓存

本目录研究训练启动阶段的模型和优化器初始化、运行时预热，以及编译和 autotune 缓存。结合 `dots-score` 的实现和提交历史，梳理首个稳定训练步骤之前需要完成哪些准备，以及这些准备如何影响启动耗时和资源占用。

## 重点内容

- **初始化流程**：模型、优化器和运行资源的创建顺序、依赖和同步边界。
- **运行时预热**：warmup 执行哪些计算、准备哪些状态，以及预热与正式训练之间的状态处理。
- **编译缓存**：Triton、FlashAttention 等相关编译缓存的生成、复用和失效条件，以及多进程访问的约束。
- **Autotune**：候选配置搜索、shape 与配置的对应、结果缓存及复用条件。
- **启动性能与正确性**：初始化和同步耗时、重复编译、缓存失配和预热副作用的分析，以及相关 bugfix。

## 与其他专题的关系

- [DSA warmup](../12_DSA_warmup/README.md) 是 indexer 的训练阶段；本目录的 warmup 是正式执行前的运行时准备。
- [CUDA Graph](../18_CUDA_Graph/README.md) 对预热和捕获前状态有具体要求；[融合算子](../23_Fused_kernels/README.md) 提供需要编译或调优的计算实现。
- [进程组与通信拓扑](../36_Process_groups/README.md) 研究分布式初始化，本目录关注它在整体启动过程中的位置。

后续资料重点记录启动时序、缓存命中与失效条件、相关 commit，以及冷启动和缓存复用后的耗时对照。
