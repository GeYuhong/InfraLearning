# RoPE、YaRN 与位置编码

本目录研究旋转位置编码（RoPE）、YaRN 及相关位置编码实现。结合 `dots-score` 的实现和提交历史，理解位置信息如何进入模型计算，以及长序列、不同张量布局和低精度训练对实现提出的要求。

## 重点内容

- **编码原理与参数**：旋转频率、维度、位置索引和缩放参数的含义，以及 YaRN 等长上下文扩展方式。
- **应用位置与布局**：编码如何作用于 Q/K，如何处理 attention head、投影后的维度及不同张量布局。
- **数值精度**：FP32 系数、旋转运算精度和类型转换对结果与梯度的影响。
- **缓存与动态长度**：位置系数的生成、缓存复用和更新边界，以及不同序列长度下的行为。
- **实现演进**：相对/绝对位置编码等相关历史、融合实现、并行适配和典型边界问题。

## 与其他专题的关系

- [MLA](../13_MLA/README.md) 研究投影与 K/RoPE 相关数值控制；本目录解释位置编码自身的计算。
- [上下文并行](../06_Context_parallel/README.md) 与[文档 Mask](../30_Document_mask/README.md) 涉及位置索引和序列边界，本目录关注切分或拼接后的编码语义。

后续资料重点记录公式与 shape 对照、位置索引示例、相关 commit，以及长序列和混合精度下的数值验证。
