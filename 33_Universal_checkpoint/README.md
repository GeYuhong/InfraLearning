# 通用检查点（Universal Checkpoint）

本目录研究 Universal Checkpoint 对模型、优化器和训练进度的统一表示与保存恢复接口。结合 `dots-score` 的实现和提交历史，梳理不同模块和分片方式如何描述自身状态，以及这些状态在恢复时如何与目标训练配置对应。

## 重点内容

- **状态模型与元数据**：模型和优化器状态的标识、shape、dtype、分片信息及其他恢复所需的描述。
- **统一接口与计划**：保存/加载计划、plan cache 和状态映射的职责，以及计划复用和失效的条件。
- **模块与并行适配**：FSDP、DDP、视觉和音频编码器等状态如何进入统一表示，梳理不同布局的约束。
- **恢复语义**：参数、优化器状态、optimizer reset 和训练数据进度的处理，以及跨配置恢复需要满足的条件。
- **一致性与演进**：元数据兼容、dtype 与布局变化、遗漏状态等问题的验证，追踪相关接口和格式的演进。

## 与其他专题的关系

- [分布式检查点](../34_Distributed_checkpoint/README.md) 研究实际保存加载、异步执行和 I/O；本目录重点是统一状态语义和接口。
- [FSDP/HSDP](../04_FSDP_HSDP/README.md) 提供分片布局背景；[SamplePlan](../31_SamplePlan/README.md) 说明采样计划与训练进度的恢复要求。
- [激活重算](../20_Recompute/README.md) 中的 checkpoint 用于管理中间激活，本目录讨论持久化训练状态。
