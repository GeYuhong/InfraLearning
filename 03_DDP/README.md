# DDP、数据并行梯度同步与参数缓冲区

本目录研究分布式数据并行（DDP）中的梯度同步和参数缓冲区。结合 `dots-score` 的实现和提交历史，理解多个数据并行副本如何累积、归约梯度，以及 bucket 和缓冲区如何支撑正确且高效的训练。

## 重点内容

- **同步语义**：梯度累积、all-reduce、梯度归一化和同步边界，分析 microbatch 与训练步骤之间的关系。
- **梯度就绪管理**：autograd hook、grad-ready 计数及梯度最终处理，排查重复通知、遗漏通知和同步顺序问题。
- **缓冲区布局**：参数与梯度的连续存储、bucket 划分、对齐、复用，以及参数视图与底层存储的对应关系。
- **通信与优化器接口**：梯度归约、参数收集和参数更新之间的依赖，以及通信重叠所需的就绪条件。
- **正确性与性能**：共享参数、梯度累积和多模块组合下的行为，评估 bucket 大小、通信次数和显存占用。
