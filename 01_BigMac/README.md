# PP/VPP 与 BigMac 调度执行

本目录以 BigMac 为重点，研究流水线并行（PP）和虚拟流水线并行（VPP）的调度与执行。结合 `dots-score` 的实现和提交历史，理解一个训练步骤中的计算、通信和依赖关系如何组织，以及调度改动如何影响正确性、吞吐和显存占用。

## 重点内容

- **调度模型**：stage、virtual stage、microbatch 的关系；1F1B、交错流水线、BigMac/Sandwich 等调度方式的执行顺序和适用条件。
- **调度器与执行器**：`pp-scheduler`、`pp-executor` 如何表达和执行调度计划，如何组织前向、反向、梯度计算及其依赖。
- **流水线通信**：stage 之间的 P2P 通信、异步收发、计算与通信重叠，以及动态 shape 下的通信约定。
- **复杂训练步骤**：encoder fusion、sequence slicing 等机制如何接入流水线，如何处理不同模块和不同长度的输入。
- **正确性与性能**：死锁、执行顺序、张量生命周期等问题的排查；流水线气泡、峰值显存和吞吐之间的取舍。
