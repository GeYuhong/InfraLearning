# MoE 架构、路由与负载均衡损失

本目录研究混合专家模型（MoE）的模型结构和路由机制。结合 `dots-score` 的实现和提交历史，理解 token 如何选择专家、专家如何参与计算，以及路由策略和辅助损失如何影响训练行为与负载分布。

## 重点内容

- **模型结构**：专家层、shared expert、grouped MLP 等模块的职责和前反向计算关系。
- **路由机制**：top-k 选择、路由权重、router bias，以及 token 到逻辑专家的分配过程。
- **负载均衡与损失**：aux loss 等机制如何约束路由，如何理解负载统计和相关训练指标。
- **Token 管理**：token drop、capacity、padding 等行为对计算量、输出和梯度的影响。
- **训练稳定性与实现演进**：路由数值、梯度传播、统计更新等问题的排查，以及模型和路由相关 commit 的发展脉络。

## 与其他专题的关系

- [Dispatch overlap](../08_Dispatch_overlap/README.md) 负责 token 在设备之间的发送、回收和通信重叠；本目录关注路由产生的分配结果及专家计算语义。
- [EPLB](../09_EPLB/README.md) 负责专家的物理放置、复制与重映射。本目录中的负载均衡重点在路由选择和损失约束，两者可以共同作用。

后续资料重点记录模型结构图、路由与损失公式、关键代码入口，以及相关 commit、训练指标和典型问题。跨专题的改动可互相引用。
