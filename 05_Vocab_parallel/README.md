# 张量并行、序列并行与词表并行

本目录以词表并行为重点，同时覆盖相关的张量并行（TP）和序列并行（SP）。结合 `dots-score` 的实现和提交历史，研究模型张量如何切分到不同 rank，以及前向输出、反向梯度和 loss 如何保持与相应非分片计算一致的语义。

## 重点内容

- **张量并行基础**：线性层和中间激活的切分方式，all-reduce、all-gather、reduce-scatter 等集合通信的作用，以及前反向的对应关系。
- **序列并行**：激活沿序列维度的分布、与 TP 的配合，以及归一化等操作的计算和梯度语义。
- **词表并行**：embedding、输出 logits 和交叉熵在词表分片后的实现，包括全局归约、目标 token 所属分片及梯度计算。
- **数值与边界条件**：loss 归一化、mask、padding、分片边界和混合精度对结果的影响。
- **实现演进与性能**：并行算子的通信优化、接口调整、兼容适配和相关 bugfix，以及通信量与显存收益的衡量。

- [FSDP/HSDP](../04_FSDP_HSDP/README.md) 研究训练状态的分片生命周期；本目录关注具体算子和张量的并行计算。
