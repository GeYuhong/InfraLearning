# 数据预处理、加载、预取与 Mmap/Cache

本目录研究训练数据从原始数据到可用 batch 的处理链路，包括预处理、数据集表示、加载、预取、内存映射和缓存。结合 `dots-score` 的实现和提交历史，梳理数据如何及时、准确地送入训练，并在恢复运行时保持进度一致。

## 重点内容

- **数据准备**：文本清洗、去重、多模态预处理，以及 GPT/indexed dataset 等数据表示和索引组织。
- **读取与加载**：dataset、dataloader、preloader 的职责，异步读取和 worker 之间的数据交接。
- **Mmap 与缓存**：内存映射、数据缓存、样本映射和数据扩展/JIT 相关机制的使用与生命周期。
- **预取与资源管理**：队列、缓存容量、内存占用、I/O 等待和数据准备速度之间的关系。
- **进度与正确性**：读取状态、数据进度恢复、坏样本和边界数据的处理，追踪相关 bugfix 与性能变化。

## 与其他专题的关系

- [SamplePlan](../31_SamplePlan/README.md) 决定样本选择与数据配比；本目录实现样本的读取和准备。
- [文档 Mask](../30_Document_mask/README.md) 定义 batch 内的序列与 loss 边界；[音频编码器](../27_Audio_encoder/README.md) 说明音频特征及模型输入要求。
- [分布式检查点](../34_Distributed_checkpoint/README.md) 研究保存和恢复的执行机制，本目录记录数据进度对恢复的要求。

后续资料可围绕数据处理链路、读取与预取时序、相关 commit，以及 I/O、内存和恢复一致性案例展开。
