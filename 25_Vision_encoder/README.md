# 视觉编码器、MoEViT 与性能优化

本目录研究视觉编码器（Vision Encoder，VE）的结构、视觉 token 处理和性能优化。结合 `dots-score` 的实现和提交历史，梳理图像或视频信息如何转成模型表示，以及编码器内部计算如何适配分布式训练。

## 重点内容

- **编码器结构**：ViT、AIMv2、AGIv2 等相关实现的模块组成、输入输出和参数组织。
- **视觉专家模型**：MoEViT 等视觉 MoE 的专家层、路由和计算特点，以及与常规视觉编码器的接口关系。
- **视觉 Token**：图像与时序 token 的组织、位置和 mask 语义，以及不同输入形状下的处理。
- **算子与通信优化**：QKV、row mask 等融合和 encoder CP 通信，分析布局、计算与通信之间的依赖。
- **训练正确性与性能**：参数梯度、精度和边界输入的验证，以及不同 shape 下的计算量、显存和吞吐。

## 与其他专题的关系

- [VLM/Omni](../24_VLM_Omni/README.md) 负责视觉模块与其他模型组件的集成；本目录研究编码器内部实现。
- [VE CUDA Graph](../26_VE_CUDA_Graph/README.md) 专门研究图捕获与回放；[编码器负载均衡](../29_Encoder_balance/README.md) 研究视觉任务在 rank 之间的分配。
- [MoE](../07_MoE/README.md) 提供专家模型和路由背景，可用于理解视觉 MoE 的共性与差异。
