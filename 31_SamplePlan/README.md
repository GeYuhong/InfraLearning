# SamplePlan、分层采样与多数据源策略

本目录研究 SamplePlan、分层采样和多数据源训练策略。结合 `dots-score` 的实现和提交历史，理解训练样本如何按数据配比与阶段计划被选出，以及计划、缓存和进度如何在分布式执行中协作。

## 重点内容

- **采样计划**：SamplePlan 的表示、多阶段路由和样本选择过程，以及训练阶段与数据配比的关系。
- **分层组织**：hierarchical worker/cache 的职责、计划分发与缓存访问，以及层级之间的协作。
- **多源混合**：数据源、配比、blended dataset 和策略切换的语义，检查实际样本选择与计划是否一致。
- **计划准备与缓存**：分布式 cache build、异步准备和缓存复用，分析初始化开销和执行时的依赖。
- **进度与恢复**：采样状态、计划恢复和分布式一致性，排查恢复后样本重复、遗漏或配比偏移等问题。

## 与其他专题的关系

- [数据管线](../32_Data_pipeline/README.md) 负责具体数据的读取、预取和处理；本目录关注选择哪些样本及其顺序。
- [通用检查点](../33_Universal_checkpoint/README.md) 整理训练状态的保存语义，本目录说明采样计划和进度需要保存的内容。

后续资料重点记录采样与路由流程、层级缓存结构、相关 commit，以及数据配比和恢复一致性的验证案例。
