# 融合算子与底层 Kernel 优化

本目录研究训练框架中的通用融合算子和底层 kernel 优化。结合 `dots-score` 的实现和提交历史，理解算子融合、数据布局和编译执行如何减少访存、启动开销或中间存储，并保持前反向语义一致。

## 重点内容

- **常见融合**：LayerNorm/RMSNorm、SwiGLU/GeLU、bias/dropout，以及 linear 与 activation 等组合的计算关系。
- **实现方式**：现有 CUDA、Triton、JIT、torch.compile 等实现的接口、适用 shape 和执行特点。
- **布局与数据搬运**：连续性、stride、对齐、临时张量和存储复用对性能及正确性的影响。
- **前反向与精度**：融合前后的计算等价条件、梯度路径、累加精度和不同 dtype 的边界行为。
- **验证与性能分析**：参考实现对照、不同 shape 的表现、访存与计算开销，以及版本适配和典型回归。

## 与其他专题的关系

- [混合精度](../22_Mixed_precision/README.md) 定义精度与缩放语义；本目录研究这些语义如何落到算子实现。
- DSA、Muon、视觉和音频编码器中的专用算子，同时关联对应专题，便于理解调用背景。
- [启动与缓存](../35_Startup/README.md) 研究编译和 autotune 的缓存生命周期；本目录重点是算子自身的实现与效果。
