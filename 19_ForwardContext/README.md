# 统一 ForwardContext 与重算语义

本目录研究统一的 ForwardContext 如何表达训练执行阶段，并协调正常前向、重算、CUDA Graph 捕获与回放的行为。结合 `dots-score` 的实现和提交历史，梳理模块如何依据执行上下文处理统计、状态更新和其他副作用。

## 重点内容

- **阶段表达**：正常执行、重算和图执行相关状态的定义、查询与传播，以及嵌套调用的边界。
- **副作用管理**：指标累计、计数器、缓存和状态更新何时发生，如何避免重算或捕获导致重复更新。
- **接口统一**：旧有局部标记如何迁移到统一上下文，调用方与被调用模块各承担哪些职责。
- **组合行为**：activation checkpoint、FSDP、CUDA Graph、EPLB 等机制如何使用上下文并保持状态一致。
- **正确性验证**：异常退出、嵌套上下文和不同执行路径下的状态恢复，以及相关回归案例。

## 与其他专题的关系

- [激活重算](../20_Recompute/README.md) 研究重算策略和张量生命周期；本目录研究执行阶段的表达与副作用约定。
- [CUDA Graph](../18_CUDA_Graph/README.md) 研究图的捕获和回放；本目录说明图执行期间模块如何判断上下文。
- [EPLB](../09_EPLB/README.md) 等有状态模块可作为实例，分析前向、反向和重算中的状态使用方式。
