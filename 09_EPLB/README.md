# 专家并行负载均衡（EPLB）

本目录研究专家并行负载均衡（Expert Parallel Load Balancing，EPLB）。结合 `dots-score` 的实现和提交历史，理解如何通过专家的物理放置、复制和重映射改善设备间负载，并保持路由、参数和梯度的一致性。

## 重点内容

- **逻辑专家与物理专家**：专家 placement、副本和设备之间的对应关系，以及路由结果如何映射到具体执行位置。
- **负载统计与调整**：负载如何统计，如何据此决定专家放置或副本分配，以及映射更新的时机和代价。
- **副本训练语义**：专家副本的参数一致性、replica gradient 归约，以及更新过程中需要满足的条件。
- **状态与执行一致性**：映射、统计和相关状态在前向、反向及重算中的生命周期，避免同一次计算使用不一致的状态。
- **组合适配与验证**：与 VPP、SimpleHC（SHC）、CUDA Graph 等机制组合时的约束，以及负载改善、额外开销和数值一致性的验证。

## 与其他专题的关系

- [MoE](../07_MoE/README.md) 研究路由选择和负载均衡损失；本目录研究专家在设备上的部署、复制与映射。
- [Dispatch overlap](../08_Dispatch_overlap/README.md) 研究 token 的发送和回收；两者通过专家映射和通信元数据衔接。
- [BigMac](../01_BigMac/README.md) 提供流水线执行背景；涉及 VPP 时，本目录关注 EPLB 状态的使用与更新时机。
