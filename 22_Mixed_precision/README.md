# FP8、MXFP8 与 BF16 混合精度训练

本目录研究训练中的 FP8、MXFP8、BF16 及相关混合精度机制。结合 `dots-score` 的实现和提交历史，梳理参数、激活、梯度和优化器状态的精度选择，以及低精度计算的缩放、转换和数值约束。

## 重点内容

- **精度分工**：FP32、FP16、BF16、FP8 等类型在存储、计算和累加中的作用，以及转换发生的位置。
- **FP8 配置**：recipe、缩放策略和相关状态的更新，分析前向与反向的数值要求。
- **MXFP8**：1D/2D、block scaling 等布局和缩放方式，以及与具体算子接口的关系。
- **框架集成**：Transformer Engine 低精度接口、精度感知优化器，以及重算、并行和图执行中的状态管理。
- **数值与性能**：溢出、误差、梯度稳定性和训练指标的检查，以及计算效率与显存占用的衡量。

- [Muon](../10_Muon/README.md) 研究优化器内部数值过程；[CUDA Graph](../18_CUDA_Graph/README.md) 研究低精度状态在捕获与回放中的使用。
