# 视觉编码器 CUDA Graph 与 Replay

本目录研究视觉编码器的 CUDA Graph 捕获与回放。结合 `dots-score` 的实现和提交历史，梳理视觉输入的图执行边界、共享显存池及梯度缓冲区生命周期，并分析其与多模态训练调度的配合。

## 重点内容

- **捕获范围与输入**：视觉编码器哪些部分进入图，如何组织 shape、静态输入和回放所需的元数据。
- **回放方式**：capture/replay、fireall 等相关路径的执行顺序，以及图输入输出如何连接后续模型计算。
- **共享显存池**：graph pool 的使用、输出和临时存储的生命周期，以及跨图复用的条件。
- **梯度管理**：main-grad 的释放、重建和复用，梳理参数视图、存储与反向计算的依赖。
- **融合与验证**：图内视觉计算融合、参考回放、数值一致性，以及捕获成本、峰值显存和吞吐。
